# FormWise-AI 零代码应用搭建平台 · 客户使用手册

本手册面向企业业务人员、部门经理和企业管理员，说明如何用自然语言搭建表单、配置审批流程、提交业务数据和完成审批，**无需编写代码**。

适用场景：员工请假、费用报销、物资采购、加班申请、出差审批、业务登记等企业内部轻量业务。

---

## 1. 登录与角色

打开平台登录页，使用企业分配的邮箱和密码登录。

演示环境可使用以下账号（密码均为 `Admin123!`）：

| 角色 | 邮箱 | 适合做什么 |
|------|------|------------|
| 企业管理员 | admin@formwise.local | 搭表单、配流程、管权限、看全部数据 |
| 部门经理 | manager@formwise.local | 审批待办、查看相关数据 |
| 员工 | employee@formwise.local | 填写已发布的表单、查看自己的提交 |

登录后进入**工作台**，左侧菜单为全部功能入口，右上角可查看未读消息并退出。

> 不同角色看到的按钮可能不同。例如员工通常不能发布表单、不能改他人权限，这是正常的权限控制。

## 2. 五分钟走通一次（推荐先看）

以「员工请假」为例，完整闭环如下：

1. **管理员**进入「AI 表单引擎」→「AI 生成表单」，用一句话描述需求并生成。
2. 在预览区确认字段，必要时在右侧改名称、是否必填、选项，点**保存**再点**发布**。
3. 进入「工作流引擎」，可一键套用「员工请假」等模板，或打开编排画布绑定刚才的表单并**发布**流程。
4. **员工**在表单列表点**填写**，提交请假信息，系统自动启动审批。
5. **经理**在「待办审批」中点**通过**或**驳回**。
6. 任何人（有权限）可在「数据管理」查看归档记录，在「流程追踪」查看每一步审批意见。

到这里，一套企业内部应用就已经可用。

## 3. 用 AI 搭建表单

菜单：**AI 表单引擎**

### 3.1 用自然语言生成

1. 点击右上角 **AI 生成表单**。
2. 在左侧文本框用业务语言描述需求，例如：

   > 搭建员工请假审批表，包含姓名、部门、岗位、请假类型、请假时长、请假原因，部门变更联动岗位选项，时长必填且大于 0，需要部门经理审批。

3. 点击 **解析并生成**。系统会自动：
   - 拆出字段、控件类型（输入框、下拉、日期、数字等）
   - 按「基础信息 / 业务信息 / 备注信息」分组排版
   - 尽量带上必填和简单校验
   - 识别「部门 → 岗位」一类联动

4. 中间区域可立即预览填写效果。

### 3.2 手动微调

选中左侧字段列表中的某一项，可在右侧修改：

- 显示名称、组件类型、所属分组、占位提示
- 是否必填、数字最小值
- 下拉/单选/多选的选项（每行一条，格式：`显示名:取值`）
- 上移、下移、删除；也可点 **新增** 加字段

支持的常见控件：输入框、文本域、下拉、数字、日期、上传、单选、多选、子表单（可动态增行）。

编辑过程中会**自动保存草稿**，防止误关页面丢失。确认无误后请点 **保存**，再点 **发布**。只有已发布的表单，员工才能填写。

### 3.3 填写已发布表单

回到表单列表，已发布的表单会出现 **填写**。打开后按页面提示录入，点提交。若该表单已绑定审批流程，提交后会自动进入待办。

## 4. 配置审批工作流

菜单：**工作流引擎**

### 4.1 套用模板（最快）

平台内置模板，例如：员工请假、费用报销、物资采购、加班申请、出差审批。

点击对应模板即可生成一份**已发布的表单 + 流程**，再按企业习惯微调即可。

### 4.2 自己在画布上编排

点击 **打开编排画布**（或列表中的 **编排**）：

1. 填写流程名称，在「绑定表单」中选择已发布的表单。
2. 从左侧把节点拖到画布：发起、审批、抄送、通知、条件分支、结束。
3. 用连线表示流转方向（例如：发起 → 部门经理审批 → 结束）。
4. 点击某个节点，可配置：
   - 节点名称
   - 审批角色（如 manager / admin）
   - 超时小时数
   - 驳回规则说明
5. 点 **保存**；对外生效请再点 **发布**。
6. 需要复用时，点 **存为模板**，以后可在模板库再次套用。

### 4.3 查看流程走到哪一步

点击 **流程追踪**，左侧选一条实例，右侧时间线展示：

- 谁在哪一节点操作
- 通过 / 驳回及审批意见
- 操作时间

流程状态常见为：进行中、已通过、已驳回等。

## 5. 数据管理（自动生成的列表）

菜单：**数据管理**

表单发布并有人提交后，这里会按该表单的字段自动出现列表，无需再做一张「查询页」。

可以做的事：

- 切换上方表单，查看对应数据
- 按关键词、状态筛选，翻页浏览
- **新增 / 编辑 / 删除**（需相应权限）
- 点 **详情** 查看完整内容和关联流程
- 被驳回的单据可由发起人点 **重提**，修改后重新进入审批
- **导出 CSV** 做归档；也可导入 CSV 批量补录（表头需与字段名对应）

## 6. 待办审批与消息

### 6.1 待办审批

菜单：**待办审批**

- **待办**：需要您处理的节点。填写意见后点 **通过** 或 **驳回**。驳回后发起人可在数据管理中修改并重提。
- **已办**：您已经处理过的记录。

审批人请及时处理，以免单据在您节点超时。

### 6.2 消息中心

菜单：**消息中心**（右上角铃铛也可进入）

消息按类型查看：待办、已办、抄送、系统。点击一条即标记已读，也可 **全部已读**。提交、流转、通过、驳回会实时推送到站内消息。

## 7. 用户与权限（管理员）

菜单：**用户权限**

仅管理员（或被授予相应权限的人）使用。

- **用户**：搜索姓名/邮箱；勾选角色即可调整该用户身份（可同时担任多个角色）。
- **角色权限**：为「企业管理员 / 部门经理 / 员工」等角色勾选能力，例如：
  - 查看/编辑表单
  - 查看/管理数据
  - 查看/编辑流程
  - 用户与角色管理
  - 插件管理

原则：给岗位最小必要权限。员工能填单即可，不必开放「发布表单」「改权限」。

---

## 8. 插件中心（技术扩展人员）

菜单：**插件中心**

表单控件和流程节点采用注册方式管理。可查看平台已有组件，管理员可为扩展组件登记编码、名称并启用/停用。业务人员日常搭应用**不必进入本页**。

## 9. 使用建议与注意点

1. **先发布再填写**：未发布的表单只有设计态，员工看不到填写入口。
2. **流程要绑定表单并发布**：只发布表单、不发布流程时，提交可能只入库、不产生待办。
3. **审批角色要有对应的人**：节点设为 `manager` 时，企业里需有用户被赋予「部门经理」角色，否则待办无人接收。
4. **部门联动岗位**：预览或填写时先选部门，岗位下拉会随部门变化。
5. **草稿不是发布**：自动保存草稿只保证设计不丢，对外生效必须点发布。
6. **敏感操作**：删除数据、调整角色权限请确认对象无误，删除后相关流程记录可能一并受影响。

## 10. 常见问题

**问：生成的字段不对，要重新说一遍吗？**  
答：可以再生成一次，也可以不重新生成，直接在字段列表里改、增、删。

**问：为什么我点不了「发布」「套用模板」？**  
答：当前账号没有对应权限。请管理员在「用户权限」中勾选，或使用管理员账号操作。

**问：提交了但经理说没收到待办？**  
答：请确认：表单已发布、流程已发布且绑定该表单、审批节点角色与经理账号角色一致。可在「流程追踪」和「消息中心」核对。

**问：驳回之后怎么办？**  
答：发起人到「数据管理」找到该条，修改后点 **重提**，流程会重新开始流转。

**问：能不能对接企业微信 / OA？**  
答：平台接口已按标准设计，可由贵司信息化同事后续对接。本手册仅覆盖平台内操作。
