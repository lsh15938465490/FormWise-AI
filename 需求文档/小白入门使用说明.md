# FormWise-AI 小白入门使用说明

这份说明是写给**第一次接触本平台、不会写代码**的同事看的。  
你只要会用浏览器、会打字、会点鼠标，就可以跟着做。

可以把它理解成：以前请假、报销要填纸质单、找领导签字、再交给行政存档；现在改成在网页上完成同样的事。

---

## 先记住三件事

1. **不同账号能做的事不一样。**  
   管理员负责“搭好表单和审批路线”，员工负责“填单”，经理负责“签字（点通过或驳回）”。
2. **没点「发布」的东西，别人用不了。**  
   就像草稿箱里的邮件，只有点发送（这里叫「发布」）对方才能看到。
3. **本说明里的例子都可以原样照抄。**  
   演示环境建议用下面三个账号轮流登录，体会完整过程。

---

## 一、怎么打开、怎么登录

1. 用电脑打开浏览器（建议 Chrome 或 Edge）。
2. 在地址栏输入公司给的网址。  
   本地演示一般是：`http://localhost:5175`
3. 进入登录页后，填写邮箱和密码，点 **登录**。

演示环境三个账号（密码都是 `Admin123!`）：

| 你扮演谁 | 邮箱 | 平时干什么 |
|----------|------|------------|
| 系统管理员（王行政） | `admin@formwise.local` | 搭表单、配审批、管人和权限 |
| 部门经理（张经理） | `manager@formwise.local` | 审批员工提交的单子 |
| 普通员工（李员工） | `employee@formwise.local` | 填请假、报销等已发布的表单 |

登录成功后，你会看到：

- **左边**：一列菜单（工作台、AI 表单引擎、工作流引擎……）
- **上面**：平台名称、右上角你的名字、铃铛（消息）、退出
- **中间**：当前页面内容

点右上角 **退出** 可以换账号。换人操作时，务必先退出再登录另一个邮箱。

## 二、左边菜单是干什么的（用大白话）

| 菜单名字 | 你可以把它想成 | 谁最常用 |
|----------|----------------|----------|
| 工作台 | 首页，看有多少张表、有几件待办 | 所有人 |
| AI 表单引擎 | 设计「要填哪些格子」的地方 | 管理员 |
| 工作流引擎 | 设计「填完单子要找谁签字」的地方 | 管理员 |
| 数据管理 | 所有已提交单据的档案柜 | 管理员 / 有权限的人 |
| 待办审批 | 领导的签字台 | 经理 |
| 消息中心 | 站内通知（谁提交了、谁驳回了） | 所有人 |
| 用户权限 | 给同事发「工牌角色」 | 管理员 |
| 插件中心 | 技术人员扩展控件用的，日常可以不进 | 技术人员 |

页面上有时会出现英文状态，对照如下即可：

| 你看到的英文 | 中文意思 |
|--------------|----------|
| DRAFT | 草稿，还没对外使用 |
| PUBLISHED | 已发布，员工可以填 |
| PENDING / IN_PROGRESS | 审批进行中 |
| APPROVED | 已通过 |
| REJECTED | 已驳回 |
| submitted | 已提交 |
| archived | 审批通过后归档 |
| rejected | 审批驳回 |

## 三、推荐你第一次这样练（10 分钟）

目标：管理员点一下模板，员工填一张请假单，经理点通过。

下面分角色写。请严格按顺序做，不要三个账号同时开着搞混。

### 第 1 步：管理员套用「请假」模板（最快的办法）

1. 用 **管理员** 登录：`admin@formwise.local` / `Admin123!`
2. 点左边 **工作流引擎**。
3. 页面上方有一块 **流程模板库**，里面有一排按钮，例如：
   - `人事 / 员工请假`
   - `财务 / 费用报销`
   - `行政 / 物资采购`
   - 等等
4. 用鼠标点一下 **「人事 / 员工请假」**。  
   点完后，下面的流程列表里会出现一条新流程（名称类似「员工请假流程」），状态一般是 **PUBLISHED（已发布）**。
5. 再点左边 **AI 表单引擎**。  
   列表里也会多出一张叫 **员工请假** 的表单，状态同样应是已发布。

到这里：表已经搭好，审批路线也搭好了。管理员可以先 **退出**。

> 这一步相当于：行政把「请假单模板」和「找经理签字」的规矩一次性复印好，放到前台。

### 第 2 步：员工填写请假单

1. 用 **员工** 登录：`employee@formwise.local` / `Admin123!`
2. 点左边 **AI 表单引擎**。
3. 找到名称是 **员工请假** 的那一行，右边有蓝色字 **填写**，点它。
4. 按页面提示填，下面是一份**可直接照抄**的示例：

   | 栏位 | 填什么（示例） |
   |------|----------------|
   | 姓名 | 李员工 |
   | 部门 | 研发部（若是下拉，选一项即可） |
   | 请假类型 | 年假（或病假、事假，按选项选） |
   | 请假时长 | `1` |
   | 请假原因 | 家里有事，请假一天 |

5. 点页面上的 **提交**（或确认按钮）。

提交成功后：

- 这张单已经交给系统；
- 张经理的「待办审批」里会出现一条任务；
- 李员工可以 **退出**。

如果提交时提示某项必填，按红字把空着的格子补上再提交。

### 第 3 步：经理审批通过

1. 用 **经理** 登录：`manager@formwise.local` / `Admin123!`
2. 点左边 **待办审批**。
3. 确认当前是 **待办** 这一页（不是「已办」）。
4. 你会看到类似：
   - 标题：部门经理审批
   - 下面一行：员工请假流程 · PENDING
5. 上方有一个意见框，默认可能是「同意」。可以改成：

   > 同意，注意交接工作。

6. 点右边绿色/主色按钮 **通过**。

通过后，这条会从「待办」消失。点 **已办**，能看到刚才处理过的记录。

右上角铃铛数字可能会增加，那是系统通知你「有待办」或「流程有变化」。点铃铛可进 **消息中心**。

### 第 4 步：看结果（谁都可以看，演示用管理员）

1. 再登录 **管理员**。
2. 点 **数据管理**。
3. 上方下拉框选中 **员工请假** 这张表。
4. 列表里应有李员工刚交的那一条，状态多为 **archived**（表示审批走完并归档）。
5. 再点 **工作流引擎** → 右上角 **流程追踪**。  
   左边点一条实例，右边时间线能看到：谁提交、谁审批、写了什么意见。

恭喜：你已经完整走通「请假」这件事。

## 四、详细例子：用一句话让 AI 帮你做「加班申请表」

如果模板不够用，管理员可以用人话描述需求，让系统自动出表。

请先用 **管理员** 登录。

### 4.1 生成

1. 点 **AI 表单引擎**。
2. 点右上角蓝色按钮 **AI 生成表单**。
3. 屏幕分成三块：
   - **左边**：写需求的大文本框 +「解析并生成」
   - **中间**：实时预览（将来员工看到的样子）
   - **右边**：改某一个格子的属性（先不用管）
4. 把左边文本框里的字全部删掉，复制下面这一段进去（建议整段粘贴）：

```text
搭建员工加班申请表，包含姓名、部门、岗位、加班日期、加班时长、加班原因。
加班时长必须填写且大于 0。部门变更后岗位选项跟着变。需要部门经理审批。
```

5. 点 **解析并生成**，等几秒。

生成成功后，中间会出现一堆输入框、下拉框。左边下方会出现字段列表，例如：姓名 · Input、部门 · Select、加班时长 · NumberInput 等。

页面上方预览标题旁可能显示 **DRAFT**，表示还是草稿。

### 4.2 微调（对照真实办公室习惯改一改）

假设你希望「加班原因」必须写满，并且加班类型要能选。

**改名称示例**

1. 在左边字段列表里，点「加班原因」那一行，它会高亮。
2. 右边「显示名」如果不是你想要的，改成：`加班事由`
3. 勾选 **必填**。

**增加一个下拉选项示例**

1. 点左边字段列表上方的 **新增**。
2. 右边会出现「新字段」。
3. 按下面填写：

   | 右边的项 | 你填 |
   |----------|------|
   | 显示名 | 加班类型 |
   | 组件 | `Select`（下拉选择） |
   | 分组 | 业务信息 |
   | 占位提示 | 请选择加班类型 |
   | 必填 | 勾选 |
   | 选项 | 见下一格，**每行一条** |

   选项框请原样粘贴：

   ```text
   工作日加班:weekday
   周末加班:weekend
   节假日加班:holiday
   ```

   格式说明：`给员工看的文字:系统内部值`  
   冒号必须是英文冒号 `:`。员工只看到左边的中文。

**调整顺序示例**

选中「加班类型」，点 **上移** 或 **下移**，直到预览里它出现在「加班日期」附近。

**删错了怎么办**

选中不要的字段，点右边红色 **删除**。删错了可以再点「新增」加回来，或把需求再生成一次。

### 4.3 保存和发布（两步都要做）

1. 点左边 **保存**。成功后附近会出现「已保存配置」之类的提示。  
   编辑过程中系统也会自动存草稿，但对外生效仍必须发布。
2. 再点 **发布**。提示类似「已发布 ……」，预览旁状态变成 **PUBLISHED**。
3. 点左边菜单 **AI 表单引擎** 回到列表，确认这张加班表状态是已发布，并且出现 **填写**。

> 只保存不发布 = 只有你自己能在设计页里改，员工列表里没有「填写」。

### 4.4 给这张表配上审批（自己画一条线）

模板会连表带流程一起生成；你刚用 AI 做的表，还要手动绑流程。

1. 点 **工作流引擎** → 右上角 **打开编排画布**。
2. 上方填写：
   - 流程名称：`加班审批`
   - 绑定表单：下拉选刚才发布的加班申请表
3. 画布上通常已经有三个方块：**发起 → 部门经理审批 → 结束**。  
   用鼠标拖一拖对齐即可。中间那条线表示「填完单先到经理，经理过了才结束」。
4. 用鼠标点一下中间的 **部门经理审批** 方块，右侧可改：
   - 节点名称：`直属经理审批`（给待办列表看的标题）
   - 审批角色：选 `manager`（对应演示账号里的「部门经理」张经理）
   - 超时小时数：`24`（超过 24 小时仍未批，后续可按超时处理；演示里先填 24）
5. 点 **保存**，再点 **发布**。

审批角色和账号的对应关系（演示环境不用改）：

| 你在节点里选的角色代号 | 实际是谁 |
|------------------------|----------|
| manager | 张经理（manager@formwise.local） |
| admin | 系统管理员 |
| employee | 普通员工（一般不要设成审批人） |

如果节点写成 `manager`，但公司里没有人被赋予「部门经理」这个角色，员工交单后经理收不到待办。

### 4.5 员工填加班、经理批

退出管理员，登录员工：

1. **AI 表单引擎** → 加班那张表 → **填写**
2. 示例数据：

   | 栏位 | 示例 |
   |------|------|
   | 姓名 | 李员工 |
   | 部门 | 研发部 |
   | 岗位 | （先选部门，岗位下拉会变，再选一项） |
   | 加班日期 | 选当天 |
   | 加班时长 | `3` |
   | 加班类型 | 工作日加班 |
   | 加班事由 | 版本上线值班 |

3. 提交后，换 **张经理** 登录 → **待办审批** → 写意见「同意加班」→ **通过**。

## 五、详细例子：经理驳回，员工改完再交

还是请假这件事。假设李员工填的时长不合理。

### 5.1 员工再交一张（或用已有未通过的单）

用员工账号提交一张请假，请假时长填 `8`，原因写：`休假`。

### 5.2 经理驳回

1. 经理打开 **待办审批**。
2. 把意见框改成：

   > 时长填写有误，年假请按天填写，且需补充工作交接人。

3. 点红色 **驳回**（不要点通过）。

驳回后：

- 经理待办里这条消失；
- 李员工在消息里会收到类似「流程已驳回」；
- 数据管理里这条状态是 **rejected**。

### 5.3 员工修改后重提

1. 管理员或有数据权限的人打开 **数据管理**，选对应表单，找到状态为 **rejected** 的那一行。
2. 按页面提供的 **重提**（或编辑后再重提）入口，把内容改成：

   | 栏位 | 改成 |
   |------|------|
   | 请假时长 | `1` |
   | 请假原因 | 年假 1 天，工作已交接给王同事 |

3. 提交后，流程会**重新从头走**，张经理的待办里会再出现一条。
4. 经理这次点 **通过**。

注意：驳回不是删除。旧单还在档案里，只是状态变成驳回；重提是再走一遍审批。

## 六、详细例子：费用报销（套模板 + 自己看数据）

适合财务同事练手。

1. **管理员**登录 → **工作流引擎** → 点模板 **「财务 / 费用报销」**。
2. 到 **AI 表单引擎** 确认出现报销表，状态已发布。
3. 如需改字段：点该行 **设计**，在右边改「显示名」、选项后 **保存**、**发布**。
4. **员工**登录 → **填写**，示例：

   | 栏位 | 示例 |
   |------|------|
   | 姓名 | 李员工 |
   | 部门 | 研发部 |
   | 金额相关栏位 | `128.5`（按实际栏位填数字） |
   | 事由 | 客户拜访打车费 |

5. **经理**在待办里 **通过**。
6. **管理员**打开 **数据管理**：
   - 上方换到报销那张表；
   - 可用状态筛选（例如只看已归档）；
   - 点 **导出 CSV**，电脑上下载的 `records.csv` 可用 Excel 打开做对账。

Excel 打开后，第一行是列名（id、status 以及各个字段名），下面每一行是一张单。

## 七、工作台和消息怎么看

### 工作台

登录后第一页。几个大数字表示：

- **表单**：已经设计了多少张表
- **工作流**：有多少条审批路线
- **待办**：轮到你签字的有几件（经理要盯这个）
- **流程实例**：已经发生过多少次审批（点进去是流程追踪）

数字可以点，会跳到对应菜单。

### 消息中心

点左边 **消息中心**，或点右上角铃铛。

常见几类：

- 待办：有人把单推到你这里了
- 已办 / 系统：流程通过、驳回等
- 抄送：需要你知晓，不一定要你批

点开一条会标成已读。也可以点 **全部已读**。

## 八、管理员如何给人换角色（简要）

只有管理员需要看这一节。

1. 点 **用户权限**。
2. **用户**列表里能看到管理员、张经理、李员工。
3. 若要把某个人也变成能审批的经理：勾选他的角色为「部门经理」（可以一个人同时有多个角色）。
4. **角色权限**里可以勾选每个角色能做什么，例如：
   - 员工：能看表单、能提交数据即可
   - 经理：能看数据、能审批（待办不依赖这个勾选，主要看账号是不是 manager 角色）
   - 管理员：建议保持全部能力

原则：能少给就少给。普通员工不要打开「改权限」「发布全公司表单」，以免误操作。

## 九、自己画流程时，节点是什么意思

在 **打开编排画布** 里，左边可以拖节点（名称以界面为准）：

| 节点 | 像生活中的哪一步 |
|------|------------------|
| 发起（start） | 员工把单交到窗口 |
| 审批（approve） | 领导签字 |
| 抄送（cc） | 复印一份给相关同事知道 |
| 通知（notify） | 发个消息提醒 |
| 条件分支（condition） | 「金额大于 1000 走总经理」这类分叉（高级用法） |
| 结束（end） | 归档，流程结束 |

最小可用组合就是：

**发起 → 审批 → 结束**

连线方法：从方块边缘拖出一条线，接到下一个方块。方向一定要从「先发生的」指向「后发生的」。

改完必须 **保存** 再 **发布**，员工新提交的单才会走新路线。已经在审批中的旧单，一般仍按当时的路线走。

## 十、常见问题（按现象查）

**1. 登录后几乎没有按钮，也没有「AI 生成表单」？**  
你可能登录的是员工账号。搭表单请用管理员。这是权限，不是坏了。

**2. 表单列表有表，但没有「填写」？**  
状态还是 DRAFT。请管理员打开 **设计**，点 **发布**。

**3. 员工交了单，经理待办是空的？** 按下面逐项检查：

- 表单是否已发布  
- 流程是否已发布，并且「绑定表单」选的就是这一张  
- 审批节点角色是不是 `manager`，而你登录的是不是经理邮箱  
- 管理员是否刚改过角色（改完请经理重新登录一次）

**4. 点模板没反应或按钮是灰的？**  
当前账号没有「编辑流程」权限。换管理员。

**5. AI 生成的字段名很难看？**  
不用重新生成。点左边字段，在右边改「显示名」即可，然后保存、发布。

**6. 选项下拉是空的？**  
右边「选项」没填，或格式不对。必须一行一个，使用 `中文:英文或拼音`。

**7. 预览里改了字，刷新后又变回去？**  
预览区只是「看起来像不像」，真正改字段要在左边列表 + 右边属性，并点保存。

**8. 能不能一次多级审批（经理过了还要总监）？**  
可以。在画布上再拖一个审批节点，改名为「总监审批」，角色若演示环境没有总监，可暂时也设成 `admin`，连线改为：  
发起 → 部门经理审批 → 总监审批 → 结束。  
同一节点若有多个人都是该角色，需要这些人都通过才会往下走。

**9. 填错数字，提交前能改吗？**  
能，提交前在填写页直接改。提交后未驳回前，普通员工一般不能随便改已进入审批的内容；被驳回后走「重提」。

**10. 插件中心要不要用？**  
业务人员不用。那里是登记「输入框、下拉框」等零件的，关掉某个插件可能导致表单控件异常，请勿随意停用。
